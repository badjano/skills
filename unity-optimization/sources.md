## Authorship note

Content originates from Unity Accelerate Solutions / Studio Productions Games consulting guidance assembled into the e-books. This skill is a **practical agent checklist**, not a substitute for the full PDFs.

## Edition awareness

- Skill targets **Unity 2022 LTS** tip sets from the linked guides.
- Unity 6 has successor optimization e-books (mobile/XR/Web and consoles/PC). Prefer project’s actual Editor version docs when they diverge; keep 2022 LTS patterns unless the project is on Unity 6+ and user asks for Unity 6 guidance.
- Older 2020 LTS editions exist; do not mix edition-specific API advice without checking.
